# Protocol v2 results

Generated by `python scripts/protocol_v2_report.py --cells outputs/protocol_v2` from the collector output of
`python scripts/collect_protocol_v2.py` (rules: [docs/evaluation_protocol_v2.md](../../docs/evaluation_protocol_v2.md)).

| File | Content |
|---|---|
| `tables.md` | every table below in one file |
| `leaderboard.md`, `vlm_per_seed.md`, `failure_profile.md`, `matrix.md` | leaderboard, per-seed graded score, strict PASS by conflict type, 25 × 14 cell matrix |
| `proceed_start.md`, `release_followup.md` | PROCEED start timing and failure classes; STOP/HOLD release follow-up |
| `query_cap_green_stop.md` | green_stop, every 1.5 s vs 3-query cap, seeds 0–4 |
| `weight_sensitivity.md` | uniform-weight and ±25 % perturbation rankings |
| `green_stop_runs.md`, `green_stop_seconds_*.md` | green_stop ego-vs-environment per run and second by second |
| `timing.md` | simulation clock, decision cadence, VLM input frame age, control readback lag |
| `data/cells_v2.csv` | one row per episode (665): verdict, credit, front-bumper clearance, PROCEED timing, release follow-up, query count |
| `data/leaderboard_v2.csv`, `data/leaderboard_v2.json` | per-model aggregates and per-seed scores |
| `data/vlm_query_cap_green_stop_v2.csv` | query-cap comparison |

The tables that read per-tick telemetry (green_stop, timing) need the recorded episode directories referenced in
`cells_v2.csv`; the lane margins also need the exported Town03 map.
